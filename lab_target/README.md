# Lab Target

Small local site with known weaknesses. Use it to check WebSET Start Scan.

It listens on `127.0.0.1` only. Do not deploy it, and do not scan anything you are not allowed to test.

No extra packages. Python 3.12 is enough.

## Run the site

From this folder:

```bash
python app.py
```

Leave that window open. Open http://127.0.0.1:5000/ in a browser. You should see **Lab Target**.

Stop it with Ctrl+C.
